# Charts

Generated by `python src/eval/generate_charts.py`. SVG, because matplotlib/numpy/PIL are unavailable and a raster chart would need a font rasteriser.

- **fig1 overall accuracy** — `fig1_overall_accuracy.svg`
- **fig2 category intervals** — `fig2_category_intervals.svg`
- **fig3 dev to test** — `fig3_dev_to_test.svg`
- **fig4 retrieval recall** — `fig4_retrieval_recall.svg`
- **openqa factuality** — `openqa_factuality.svg`

The first four come from `generate_charts.py`. The open-ended figure is built by
its own module, `python src/eval/openqa_chart.py`, because it is not an accuracy
chart: it is three rates whose denominators differ (correct / incorrect / not
attempted), drawn as one composition per arm. Its PNG twin for the submission PDF
is produced by `python src/scripts/openqa_asset.py`, which cross-checks both
renderings against this SVG and fails if they disagree.
